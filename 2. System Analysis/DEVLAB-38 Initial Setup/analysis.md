# Systems Analysis

This section talks about the website data flow and identifies system input and output

# Details

This website will include a home page called index.jsp. From there users will be able to register and log in. There will also be links to locate to about.jsp, locations.jsp, products.jsp, services.jsp, contact.jsp. There will also include forums and ads on the home page, social media connections, forms for contacting or getting a quote. Users will be able to purchase products and services, go to their account and view their purchasing history, update payment method, leave reviews, and get new quotes. Users will also have the option to delete their account.
