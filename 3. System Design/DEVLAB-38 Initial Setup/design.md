# System Design

This document covers the design process for obtaining output from the input.

## Details

Once users register, their information will be stored into a SQL databbase which the website will be able to retrieve everytime they view their profile, same goes for purchases, purchase history, reviews, and quotes. Once a product has been purchased, the inventory level will be updated in the database, any services purchased will be counted for insight records. This system will make it easier for users and employees to create and pull reports regarding sales and customer interactions.
